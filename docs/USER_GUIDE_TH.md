# คู่มือ GoldScalperM15 v1.53

EA เทรดทองคำ (XAUUSD) แบบจบในวัน บน M15 — กลยุทธ์เดียว: **เบรกกรอบราคาช่วงเอเชีย เฉพาะวันที่ตลาดผันผวน วันละ 1 ไม้**, เสี่ยง 0.5% ต่อไม้, SL กว้างตาม ATR, ปิดทุกไม้ 20:00 (ไม่โดน swap), มีระบบกันความเสี่ยงต่อไม้, ตัวกรองข่าว, แผงควบคุม และแจ้งเตือนเข้ามือถือ

> ⚠️ **ข้อควรทราบ: เพื่อการศึกษาเท่านั้น** โปรเจกต์นี้**ไม่ใช่คำแนะนำการลงทุน** และ**ไม่ใช่การชักชวนหรือเชิญชวนให้ลงทุน**หรือเทรดผลิตภัณฑ์ทางการเงินใดๆ เผยแพร่เพื่อเป็นแนวทางศึกษาการสร้างและทดสอบ EA เท่านั้น การเทรดทองคำและผลิตภัณฑ์ที่ใช้ Leverage มีความเสี่ยงสูงที่จะขาดทุน ผล Backtest ไม่ได้รับประกันผลในอนาคต ควรทดสอบบนบัญชี Demo ก่อนเสมอ ผู้ใช้รับผิดชอบการใช้งานและผลการเทรดของตนเองทั้งหมด

## เงินทุนและประเภทบัญชี

คำนวณ Lot จาก **Equity × 0.5% ต่อไม้** (`InpRiskPct`) โดยนับระยะ SL จากราคาเข้าจริง + เผื่อ slippage + ค่าคอมฯ แบบ **เข้มงวด** (`InpStrictRisk`): ถ้า lot ขั้นต่ำยังเสี่ยงเกิน 0.5% EA จะ **ข้ามไม้ ไม่ฝืนเปิด** และแจ้งเหตุผลพร้อมเงินที่จะเสีย เลือก **ประเภทบัญชี** ตามทุน:

| ทุน | บัญชีที่ใช้ |
|---|---|
| ต่ำกว่า ~$6,000 | **Micro** หรือ **Cent** (lot เล็กกว่า Standard 100 เท่า) เริ่มที่ ~$60 |
| ~$6,000 ขึ้นไป | Standard, Micro หรือ Cent |

บนบัญชี Standard โดน SL หนึ่งไม้ที่ lot ขั้นต่ำเสีย $15–$100+ ทุนต่ำกว่า ~$6,000 สัญญาณส่วนใหญ่จะถูกข้ามตามกฎเสี่ยงไม่เกิน 0.5% หน้าต่าง **ตรวจบัญชี** ตอนเปิด EA จะบอกว่าเป็นบัญชีแบบไหน (ข้อความแนะนำยังคิดทุนที่เสี่ยง 1% ถ้าใช้ 0.5% ต้องใช้ทุนประมาณ 2 เท่า)

**เปิดบัญชี Demo แบบ Micro ที่ XM:** ที่เว็บ XM เลือก *เปิดบัญชีทดลอง* → ประเภทบัญชี **Micro** แล้วล็อกอินใน MT5 (ทำเอง) จากนั้นเช็กใน Market Watch ว่ามี GOLD และขนาดสัญญา = 1 ส่วนบัญชี Cent ของโบรกอื่นจะแสดงยอดเป็น **USC** หน้าต่างตรวจบัญชีจะแปลงเป็น $ ให้

**Preset:** `GoldScalperM15_Default.set` — เหมือนค่าเริ่มต้นของ EA (เสี่ยง 0.5%, วันละ 1 ไม้, กรองข่าว ±15 นาที)

**ผล Backtest (ค่าเริ่มต้น ทุน $10,000 เปิดกรองข่าว):** 2018–2023 +$1,022, PF 1.23, DD 8.4% (209 ไม้) · 2024–ต.ค. 2026 +$2,223, PF 1.54, DD 4.0% (262 ไม้) · tick จริง ต.ค. 2024–ต.ค. 2026 +$1,638, PF 1.50, DD 3.7% (227 ไม้)

## 1. ติดตั้ง / อัปเดต EA

1. ดับเบิลคลิก **`install_to_MT5.bat`**
2. โปรแกรมจะแสดงตำแหน่งที่จะติดตั้ง → กด **Y** เพื่อยืนยัน (กด **N** = ยกเลิก ไม่แตะ MT5)
3. มันจะ: คอมไพล์ → คัดลอก EA ไปที่ `MQL5\Experts\MyEA` → คัดลอกไฟล์ `.set` ไปที่ `MQL5\Presets`

ทุกครั้งที่แก้โค้ดใน `GoldScalperM15.mq5` ให้รันไฟล์นี้ซ้ำเพื่ออัปเดต

ถ้ามี **MT5 แบบพกพาที่ `D:\MT5_GoldScalper`** (เปิดด้วย `terminal64.exe /portable` โปรแกรมกับข้อมูลอยู่โฟลเดอร์เดียวกัน) ตัวติดตั้งจะติดตั้งลงตัวนั้น ถ้าไม่มีจะใช้ MT5 ใน `C:\Program Files\MetaTrader 5` ถ้าไว้ที่อื่นให้แก้บรรทัด `PORTABLE=` ในไฟล์

## 2. ใส่ EA บนกราฟ

1. เปิดกราฟ **XAUUSD** (ชื่ออาจต่างตามโบรก เช่น `XAUUSDm`, `GOLD`) — timeframe อะไรก็ได้ EA ใช้ M15 เสมอ
2. กด **Ctrl+N** → Expert Advisors → MyEA → ลาก **GoldScalperM15** ไปวางบนกราฟ ใช้ **กราฟเดียว** เท่านั้น (ตั้งแต่ v1.51 ถ้ามีตัวที่สองบนสัญลักษณ์เดียวกัน ตัวใหม่จะไม่เริ่มทำงาน)
3. แท็บ **Common** → ติ๊ก **Allow Algo Trading**
4. แท็บ **Inputs** → ค่าเริ่มต้นคือค่าที่ผ่านการทดสอบแล้ว (หรือกด **Load** `GoldScalperM15_Default.set`) → OK
5. ที่แถบเครื่องมือด้านบน ปุ่ม **Algo Trading** ต้องเป็นสีเขียว

**ปุ่ม**
- **หยุดชั่วคราว / เทรดต่อ** — หยุดเปิดไม้ใหม่ (ไม้ที่ถืออยู่ยังดูแล SL/TP/Trailing ต่อ) ค่าจะถูกจำไว้แม้ปิด-เปิด MT5 ใหม่
- **Test (ทดสอบ)** — เปิด BUY lot ขั้นต่ำจริง (มี SL) แล้วปิดหลังถือ 0.1 วินาที (`InpQuickTestHoldMs` = 100) บอกเวลาเปิด/ปิดและค่าใช้จ่าย เพื่อเช็กว่าระบบไม่ค้าง ไม่นับเป็นไม้ของวัน ใช้ได้เฉพาะ Demo เว้นแต่ตั้ง `InpQuickTestReal = true` ใน console กดปุ่ม `T`
- **ปิดทุกไม้** — ปิดเฉพาะออเดอร์ของ EA นี้ (มีหน้าต่างให้ยืนยันก่อน) ออเดอร์ที่คุณเปิดเองไม่โดนปิด

**ทดสอบระบบบน Demo** — ตั้ง `InpTestMode = true` (บัญชี Demo เท่านั้น บัญชีจริงจะถูกปฏิเสธ) EA จะเปิดไม้จริง `InpTestTrades` ไม้ (ค่าเริ่มต้น 3) ทีละไม้ สลับ BUY/SELL ถือไม้ละ `InpTestHoldMin` นาทีแล้วปิด โดยไม่รอสัญญาณและไม่สนเวลาเทรด ใช้เช็กว่าการส่งคำสั่ง SL แจ้งเตือนมือถือ การวิเคราะห์ไม้แพ้ การพักหลังแพ้ และ journal ทำงานจริง เสร็จแล้วตั้งกลับเป็น false

**หน้าต่าง PowerShell (console)** — ดับเบิลคลิก `GS15_Console.bat` ในโฟลเดอร์โปรเจกต์ แสดงสถานะ EA แบบสด และบันทึกเหตุการณ์แยกสี (ใหม่สุดอยู่บน): เปิดไม้, ชนะ, แพ้ (พร้อมเหตุผล), ข้ามไม้ (พร้อมเงินที่จะเสีย), ข่าว และคำเตือน ปุ่มลัด: `P` หยุด/เทรดต่อ, `A` ตรวจบัญชี, `T` ทดสอบส่งคำสั่ง, `C` ปิดทุกไม้ (พิมพ์ CLOSE ยืนยัน), `L` เปิด log เต็มใน Notepad, `Q` ออก คำสั่งถึง EA ภายในประมาณ 1 วินาที และ EA ทำงานปกติแม้ไม่เปิดหน้าต่างนี้ (ปิดได้ด้วย `InpConsole = false`)

**ปุ่ม Console บนกราฟ** — มุมขวาบนของกราฟ: **▶ Open console** เปิดหน้าต่าง console, **■ Close console** ปิด MT5 ไม่ให้ EA เปิดโปรแกรมอื่นได้ถ้าไม่ใช้ DLL จึงมีตัวช่วยเล็กๆ ที่รันเบื้องหลังทำแทน: รัน `powershell -ExecutionPolicy Bypass -File tools\Install-ConsoleLauncher.ps1` ครั้งเดียว มันจะใส่ "GoldScalper Console Launcher" แบบซ่อนไว้ใน Startup ของ Windows แล้วเริ่มทำงานทันที ส่วน EA แค่เขียนไฟล์คำขอ ถ้าตัวช่วยไม่ได้รัน ปุ่มจะขึ้น **Console (set up)** และกดแล้วบอกวิธีแก้ ถอนด้วย `-Remove` ซ่อนปุ่มด้วย `InpConsoleButton = false` ควรเปิด MT5 และตัวช่วยจากฝั่ง Windows ของคุณเอง (เมนู Start, ทางลัดบน Desktop, Startup) เพราะโปรแกรมที่ถูกเปิดจากในแอปที่รันแบบแยกพื้นที่ อาจได้โฟลเดอร์ `%APPDATA%` คนละชุด ทำให้ console มองไม่เห็น EA

**หัวข้อข่าว** — ใต้บันทึกเหตุการณ์ console แสดงหัวข้อข่าวล่าสุดจาก RSS ของ BBC, CNBC และ InfoQuest อัปเดตเบื้องหลังทุก 10 นาที เป็นข้อมูลให้ดูเท่านั้น EA ไม่ได้ใช้เทรด กด `H` เพื่อซ่อน/แสดง รายชื่อแหล่งข่าวแก้ได้ที่ต้นไฟล์ `tools\GS15_Console.ps1`

## 4. กลยุทธ์และค่าสำคัญ

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `InpRangeStartHour` / `InpRangeEndHour` | 0 / 8 | ช่วงวัดกรอบ (เวลาเซิร์ฟเวอร์) |
| `InpMinDailyATRPct` | 1.6 | เทรดเฉพาะวันที่ ATR รายวัน ≥ 1.6% ของราคา |
| `InpSL_ATR` | 4.0 | SL = 4 × ATR (M15) ไม่ตั้ง TP / Breakeven / Trailing |
| `InpMaxTradesPerDay` | 1 | วันละ 1 ไม้ (เบรกแรกของวัน) ผลทดสอบ 2018–2026: ไม้ที่ 2–3 ของวันมักเกิดหลังเบรกหลอกและแพ้บ่อยกว่า |
| `InpStopEntry` | false | true = วาง BUY STOP / SELL STOP ที่ขอบกรอบแทนการรอแท่ง M15 ปิด (ฝั่งหนึ่งเข้าแล้วยกเลิกอีกฝั่ง) เทสแล้วกำไรดีกว่าในปี 2024–2026 แต่ DD ประมาณ 2 เท่า จึงปิดไว้ |
| `InpDailyCloseHour` | 20 | ปิดทุกไม้ 20:00 (ไม่โดน swap) |
| `InpSessionGuard` | true | ปิดก่อนตลาดทองหยุดเทรดด้วย: ก่อนหมด session 10 นาที (`InpCloseBufferMin`), 22:50 ในสัปดาห์ที่เวลาฤดูร้อนสหรัฐกับยุโรปไม่ตรงกัน, 18:00 ในวันหยุดสหรัฐที่ตลาดปิดเร็ว (`InpHolidayCloseHour`) ทุกการปิดมีบันทึก CLOSEAUDIT / CLOSEDONE ในแท็บ Experts |
| `InpLotMode` | คำนวณจาก % | **Lot คงที่** (`InpLots`) หรือ **คำนวณจาก %**: Lot = Balance × `InpRiskPct` ÷ SL (จุด) (XM GOLD: 1 จุด = $1 ต่อ lot) ปัดลงเป็น 0.01 |
| `InpRiskPct` | 0.5 | % ความเสี่ยงต่อไม้ เมื่อใช้โหมดคำนวณจาก % (ห้ามเกิน `InpMaxRiskPct`) |
| `InpStrictRisk` | true | ข้ามไม้ถ้าความเสี่ยงจริง (SL + slippage + คอมฯ เทียบ Equity) เกิน `InpRiskPct` และแจ้งเหตุผล |
| `InpSlippagePts` | 30 | เผื่อ slippage ตอนโดน SL (จุด) นับรวมในความเสี่ยงจริง |
| `InpCommissionLot` | 0 | ค่าคอมฯ ไป-กลับต่อ 1 lot (XM Standard = 0) |
| `InpMaxRiskPct` | 5.0 | เพดานสุดท้าย: ข้ามไม้ถ้า SL เสียเกิน 5% ของ Equity |
| `InpMaxDDPct` | 20 | หยุดเอง (พร้อมแจ้งเตือน) เมื่อ Equity ลดลง 20% จากจุดสูงสุด 0 = ปิด ช่วง 2018–2026 ไม่เคยถึง (DD สูงสุด 14.8%) |
| `InpMaxLossStreak` | 5 | หยุดเองเมื่อแพ้ติดกัน 5 ไม้ 0 = ปิด ช่วง 2018–2026 จะเกิด 9 ครั้ง (ประมาณปีละครั้ง) |
| `InpMaxLosingDays` | 0 | หยุดเองเมื่อขาดทุนติดกัน N วัน (วันที่ไม่มีไม้ไม่นับ) 0 = ปิด เทสแบบเปิดต่อหลัง 7 วัน: N = 2 กำไรลดลงครึ่งหนึ่ง, N = 3 ดีขึ้นในปี 2018–2023 แต่แย่ลงในปี 2024–2026 |
| `InpNewsMinsBefore` / `InpNewsMinsAfter` | 15 / 15 | ช่วงงดเข้าไม้ก่อน/หลังข่าวแรงของ USD (นาที) |

| `InpMinConfidence` | 1 | คะแนนความมั่นใจขั้นต่ำ 0–4 ก่อนเข้าไม้: +1 ต่อข้อ — ตามเทรนด์ D1 (EMA50), ตามเทรนด์ H1 (EMA200), ADX H1 อยู่ 20–30, RSI(14) ≥ 70 ไปทางเดียวกับไม้ (0 = ปิด) |

### หน้าต่างวิเคราะห์บัญชี

ตอนเปิด EA (บัญชี Demo/จริงเท่านั้น) ผลวิเคราะห์จะขึ้นในแท็บ **Experts** ด้านล่างของ MT5 โดยไม่ต้องกดตอบ EA ทำงานต่อได้เลยแม้ไม่ได้อยู่หน้าคอม ส่วนเวลากดปุ่ม **ตรวจบัญชี / คำแนะนำ** บนแผง จะเป็นหน้าต่างเด้งพร้อมทางเลือก แสดง:
- บาลานซ์, leverage, ขนาดสัญญา, lot ขั้นต่ำ และมาร์จิ้น
- ถ้าโดน SL ตอนนี้จะเสียเท่าไร (คำนวณจาก ATR วันนี้) ทั้งที่ lot ขั้นต่ำและที่ค่าตั้งปัจจุบัน

แล้วสรุปผลพร้อมให้เลือกว่าจะทำอะไรต่อ:

| ผล | ทางเลือก |
|---|---|
| ทุนไม่พอ (EA จะข้ามทุกไม้) | ทำงานต่อ · หยุดชั่วคราว · เอา EA ออก พร้อมบอกทุนที่ต้องใช้ หรือทางเลือกบัญชี Micro/Cent |
| เสี่ยงสูง (เกิน 2% ต่อไม้) | เปลี่ยนเป็น Lot จาก 1% · ใช้ค่าเดิม · หยุดชั่วคราว |
| ความเสี่ยงเหมาะสม | เลือกเปลี่ยนเป็น Lot จาก 1% ได้ (lot โตตามพอร์ต) |

`InpLanguage` เลือกภาษา **English / ไทย** ของแผง แจ้งเตือน และหน้าต่าง (ค่าเริ่มต้น English ตั้งเป็น Thai เพื่อใช้ภาษาไทย) ส่วน `InpAccountCheck` เปิด/ปิดการวิเคราะห์ตอนเริ่ม และ `InpAccountPopup = true` ถ้าอยากให้ตอนเริ่มเป็นหน้าต่างเด้ง (ต้องกดตอบ EA จะรอจนกว่าจะกด) ถ้าเลือกเปลี่ยนเป็น Lot จาก 1% ในหน้าต่าง จะมีผลเฉพาะรอบนี้ ถ้าจะใช้ถาวรให้ตั้ง `InpLotMode` ใน Inputs

### วิเคราะห์ไม้แพ้

ทุกไม้ที่แพ้ EA จะแจ้งเข้ามือถือและบันทึกว่า **แพ้เพราะอะไร** (อาจมีหลายข้อ):

| รหัส | ความหมาย |
|---|---|
| FALSE_BREAK | เบรกหลอก ราคากลับเข้ากรอบ (≈95% ของไม้แพ้ใน Backtest) |
| GAVE_BACK | เคยกำไร ≥ 1 ATR แล้วกลับตัว |
| AGAINST_D1 / AGAINST_H1 | เข้าสวนเทรนด์ D1 / H1 |
| LOW_ADX | H1 ไม่มีเทรนด์ (ADX < 20) |
| WEAK_CANDLE | แท่งเบรกอ่อน ไส้ยาว |
| CHASED | เข้าไล่ราคา ปิดไกลจากกรอบเกิน 1 ATR |
| RSI_EXTREME | RSI สุดทางตอนเข้า |
| NO_FOLLOW | ราคาไม่ไปต่อ ปิด 20:00 ขาดทุน |
| LATE_ENTRY | เข้าหลัง 15:00 (ช่วงตลาด US / ข่าว) |
| NORMAL | ไม่พบจุดผิดปกติ แพ้ตามสถิติ |

เวลาทั้งหมดเป็น **เวลาเซิร์ฟเวอร์** และทดสอบกับ XM Global (GMT+2/+3)
## 5. แจ้งเตือนเข้ามือถือ (Push Notification)

1. ติดตั้งแอป **MetaTrader 5** บนมือถือ → เมนู **Settings** (หรือ Messages) → จด **MetaQuotes ID** (รหัส 8 ตัว)
2. บนคอม MT5 → **Tools → Options → Notifications**
3. ติ๊ก **Enable Push Notifications** → ใส่ MetaQuotes ID → กด **Test** (มือถือควรได้ข้อความทดสอบ) → OK

**EA จะแจ้งเตือนเมื่อ:**
- เปิดไม้ (พร้อมราคา SL/TP) / ปิดไม้ (ถึง TP, โดน SL หรือปิดเอง พร้อมกำไร/ขาดทุน)
- เข้า/ออกช่วงข่าว
- ขาดทุนถึงเพดานรายวัน หรือตัวกันความเสี่ยงสั่งหยุด
- ปิดออเดอร์ก่อนตลาดปิดวันศุกร์
- **สรุปรายวัน** (v1.51, `InpDailySummary`): หลังปิดประจำวันไม่กี่นาที — จำนวนไม้, กำไร/ขาดทุน, Balance, DD, แพ้ติดกัน, ขาดทุนติดกันกี่วัน และสถานะ
- **EA เริ่ม / หยุด** (v1.51, `InpNotifyStartStop`): ตอนเริ่มจะบอกว่าหยุดไปนานเท่าไร (คิดจากเวลาที่ไฟล์สถานะถูกเขียนครั้งล่าสุด จึงรู้แม้คอมดับหรือไฟดับ) และแจ้งตอน MT5 ปิดหรือเอา EA ออก

ปิดแจ้งเตือนบางประเภทได้ใน Inputs กลุ่ม **แจ้งเตือน** ถ้าคอมดับ MT5 ส่งอะไรไม่ได้ จะรู้จากข้อความตอน EA เริ่มทำงานอีกครั้ง
